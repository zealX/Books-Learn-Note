#### 2.1.1.1 Gabor Filter

**Gabor滤波器**是一种在图像处理和计算机视觉中广泛使用的线性滤波器，尤其擅长纹理分析和边缘检测。其设计灵感来源于人类视觉系统的生物机制，能够同时在空间域和频率域捕捉局部特征。

**数学基础**：Gabor滤波器的核心是一个**高斯函数**与一个**复正弦波**的乘积，形成如下二维表达式：
$$
G(x, y) = \exp\left(-\frac{x'^2 + \gamma^2 y'^2}{2\sigma^2}\right) \cdot \exp\left(i\left(2\pi f x' + \phi\right)\right)
$$
其中：
- $x' = x \cos\theta + y \sin\theta$  
- $y' = -x \sin\theta + y \cos\theta$  
- $\theta$：滤波器方向（如 0°, 45°, 90°等）  
- $f$：正弦波频率（决定纹理的粗细）  
- $\sigma$：高斯窗口的标准差（控制滤波器的有效区域）  
- $\gamma$：高斯窗口的椭圆度（纵横比，通常设为1）  
- $\phi$：相位偏移（影响对称性，如0°为对称，90°为反对称）



**核心原理**

- **高斯窗口**：限制滤波器的空间范围，使其具有局部性，避免全局干扰。  
- **复正弦波**：在特定方向 $\theta$ 和频率 $f$上提取特征，对应图像中的边缘或纹理。  
- **参数调节**：通过调整 $\theta$、$f$、$\sigma$ 等参数，Gabor 滤波器可适应不同方向和尺度的特征。



**关键特性**

- **方向选择性**：通过旋转坐标 $\theta$ 实现多方向特征提取。  
- **频率选择性**：高频滤波器捕捉细纹理，低频捕捉粗纹理。  
- **联合时频局部化**：高斯窗在空间和频率域均达到最优分辨率（满足“测不准原理”下限）。



**滤波器组设计**

实际应用中，通常构建**多方向+多尺度**的 Gabor 滤波器组，覆盖不同参数组合：
- **方向**：例如 0°, 45°, 90°, 135° 等。  
- **尺度**：通过改变 $f$ 和 $\sigma$ 生成不同频率的滤波器。  

每个滤波器对输入图像进行卷积，得到对应的响应图，组合后形成特征向量。



**应用场景**

- **纹理分析**：区分不同纹理模式（如木材、织物）。  
- **边缘检测**：通过反对称 Gabor 滤波器 $\phi=90°$ 增强边缘。  
- **人脸识别**：提取面部局部特征（如眼睛、嘴巴）。  
- **生物视觉建模**：模拟视皮层V1区简单细胞的感受野。



**实例说明**

假设需检测水平纹理（\(\theta=0°\)）：
1. **构造滤波器**：设定\(\theta=0°\), \(f=0.1\)（低频）, \(\sigma=5\)。  
2. **卷积操作**：将滤波器与图像进行卷积，得到响应图。  
3. **特征提取**：响应图的幅值（\(\sqrt{\text{Re}^2 + \text{Im}^2}\)）表示纹理强度。



**优缺点**

- **优点**：  
  - 对光照变化鲁棒。  
  - 多方向、多尺度特性适合复杂纹理分析。  
- **缺点**：  
  - 计算复杂度高（尤其大尺寸滤波器）。  
  - 参数需手动调节，依赖经验。



**代码示例（Python）**

```python
import cv2
import numpy as np

def build_gabor_filter(theta=0, f=0.1, sigma=5, gamma=1):
    # 生成Gabor滤波器核
    kernel_size = 30
    gabor = cv2.getGaborKernel(
        (kernel_size, kernel_size), 
        sigma, theta, f, gamma, 0, ktype=cv2.CV_32F
    )
    return gabor

# 示例：生成0°方向的Gabor滤波器
gabor_filter = build_gabor_filter(theta=0)
```
